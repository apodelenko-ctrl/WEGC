Вопросы, которые задаёт руководитель

По делу, до подключения.

Я должен передать вам своего клиента?

Нет, модель МИРА строится вокруг сохранения ваших отношений с клиентом. Передача необходимых данных для конкретной регистрации — отдельная согласованная процедура, а не продажа клиентской базы.

Сколько комиссии получает агентство?

Размер, база расчёта и момент выплаты согласуются письменно по проекту. Универсального процента для всех объектов нет. Условия можно изучить до работы; платёжная поддержка покупателя не смешивается с агентской комиссией.

Можно уже продавать все проекты из каталога?

Нет. Открытая база нужна для поиска и знакомства. До предложения клиенту подтверждаются наличие, продавец, право работать через агентство, материалы, регистрация и коммерческий график.

У нас уже есть зарубежный отдел. Зачем МИРА?

Начните не с замены отдела, а с конкретной задачи: дополнительный проект, материалы или координация регистрации. Команда, CRM и отношения с клиентами остаются вашими.

Где договор и что с рабочим входом?

Полный пакет документов открыт для чтения. Он имеет статус проекта до согласования. Оставьте заявку агентства — мы свяжемся с вами по рабочему email.
