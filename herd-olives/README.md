# HERD — Проект: импорт испанских оливок SARASA в Таиланд

Внутренняя «библия» венчура. Цель: любой новый агент/человек мгновенно входит в курс.
Читать по порядку файлы `01`…`05`. Данные — по состоянию на 2026-07 (перепроверять перед сделкой).

## Идея в одном абзаце
Битые (aliñadas) зелёные оливки Verdial бренда **SARASA** (линейка *Hechizos del Sur*), плюс
*La Picantona* (острые) и *Morenas del Sur* (чёрные без косточки). В Таиланде их нет, спрос
на средиземноморскую гастрономию у экспатов и среднего+ класса растёт, испанские оливки —
уже №1 по импорту. Заходим в премиум-ритейл («villa markets») и HORECA. Первый бюджет — $10 000
на пилотную партию (LCL, не полный контейнер).

## Ближайшие действия (СРОЧНО — июль, чтобы успеть к сезону)
1. Отправить RFQ (`05`) на info@aceitunas-sarasa.com и cs@fresharaagroexports.com.
2. Структура на старте: **SG-компания = покупатель/контрактодержатель** (платит из SG/HK/UK),
   **лицензированный тайский импортёр-дистрибьютор = importer of record** на пилот. Своё тайское
   юрлицо + FDA-лицензию оформляем параллельно (~2 недели, когда основатель в Таиланде).
3. Параллельно — подать заявку поставщика в **Villa Market** (самый быстрый вход, Пхукет) и найти
   локального дистрибьютора с готовыми отношениями с Villa/Tops (см. `06`).
4. **Бюджет:** $10k = пилот LCL (~2 паллеты), НЕ контейнер. Полный FCL под сезон = ~$50–80k landed.
   Промо (баннеры/дегустации/купоны) бюджетировать отдельно от товара.

## Тайминг под сезон
Высокий сезон нояб–апр (пик дек–фев). Цель: сентябрь ввоз → октябрь на полке. Старт всех треков —
июль, иначе к сезону не успеть (Villa 1–3 мес + FDA 7–30 дн + этикетка + море ~4–6 нед).
