# 03 — Регуляторика Thai FDA + структура юрлиц

## Импорт для продажи — обязательные требования (Thai FDA, Food Act B.E. 2522)
1. **Импортёр = тайское юрлицо** с коммерческой регистрацией + место бизнеса + помещение для
   приёмки/хранения по критериям FDA.
2. **Лицензия импортёра еды** (Form Orr.7) через FDA e-Submission.
3. **GMP-доказательство завода** (Codex / ISO 22000 / IFS / BRC / HACCP) — берём у Sarasa/Freshara.
4. Оливки = «general food» → отдельный FDA-номер продукта **не требуется**, но ввоз регистрируется
   в «Virtual Number System» под лицензией.
5. **На каждую поставку — LPI** (License Per Invoice) через National Single Window + декларация на
   таможне + осмотр образца на FDA-чекпоинте.
6. **Этикетка на тайском** обязательна: состав, аллергены, БЖУ, импортёр, срок годности.
   Некорректная тайская этикетка = задержка/арест груза.

## Пошлины и налоги
- **HS/AHTN: 2005.70**. У ЕС нет FTA с Таиландом → ставка **MFN**.
- Переработанная еда: ад валорем **30–60%**; для оливок ориентировочно **~30%** —
  **подтвердить точную ставку** (advance ruling у Thai Customs Department).
- **VAT 7%** сверх (CIF + пошлина).

## Структура юрлиц — как СТАРТОВАТЬ без тайского счёта
Основатель имеет: **SG-компанию** (счета SG + HK), **UK-счёт**; тайская компания/счёт — через ~2 недели.

**Тайский importer of record (IOR) обязателен для розничной продажи — SG-компания им быть НЕ может.**
Поэтому на пилот:
- **SG-компания = принципал/покупатель:** контракт с Sarasa/Freshara, оплата в EUR из SG/HK/UK
  (удобный FX, без тайского счёта).
- **Лицензированный тайский импортёр-дистрибьютор = IOR:** растаможка, FDA, тайская этикетка,
  постановка на полку — по договору дистрибуции/консигнации (за комиссию/маржу).

Как только тайская компания + счёт + Orr.7 готовы (основатель в Таиланде через ~2 недели) —
переводим IOR **на своё юрлицо** и убираем посредника-импортёра. Тайского юриста подключаем к
регистрации Orr.7 и договору с импортёром/дистрибьютором.

## Пакет документов на ввоз
Контракт/инвойс, packing list, B/L, COA, health/free-sale cert, сертификат происхождения,
GMP-сертификат завода, тайская этикетка (артворк), LPI, доверенность на брокера.
