В фактически активной копии WEGC:

```sh
git status --short
git fetch origin main mira/research-night-20260918
git rev-parse origin/mira/research-night-20260918
git show origin/mira/research-night-20260918:CLOUD-INBOX/START-HERE.md
git show origin/mira/research-night-20260918:CLOUD-INBOX/tasks/MIRA-LOCAL-20260918-02.md
```

Записать точный прочитанный commit в receipt. Остальные файлы читать тем же способом. Не делать checkout/reset/clean/stash и не сливать всю research-ветку ради чтения inbox. Избирательная интеграция данных/кода — отдельный проверенный LOCAL commit от актуального main с сохранением текущих изменений.

## Дальнейший обмен

LOCAL однократно добавляет короткое правило чтения этого START-HERE/QUEUE в свои существующие startup-инструкции, не перезаписывая остальные правила. Получение задания, исполнение и публикация отмечаются отдельно. Не создавать новый watcher/планировщик ради этой папки.

CLOUD при своих следующих запусках читает receipts, продолжает источники/материалы и дополняет очередь. Локальный агент остаётся единственным исполнителем продуктовой интеграции и деплоя. Эта папка сама не запускает процесс на Mac.
