## Как прочитать, не ломая текущий worktree
Пример команд для LOCAL, не выполненных облачным агентом на Mac:

```sh
git status --short
git fetch origin main mira/research-night-20260918
git show origin/mira/research-night-20260918:CLOUD-INBOX/README.md
git show origin/mira/research-night-20260918:CLOUD-INBOX/QUEUE.json
```

Читать документы можно через git show с точным ref/path из очереди. Не делать checkout/reset/clean/stash ради чтения; не сливать research-ветку целиком. Использовать собственные существующие правила сохранения незавершённой работы. Ветка main — источник свежего состояния, не место слепого переноса старых файлов.

При старте новой задачи и на безопасном checkpoint читать CLOUD-INBOX/README.md и QUEUE.json, затем актуальные локальные WORK/RESUME и issue #14. LOCAL добавляет этот указатель в существующие AGENTS/инструкции, сохраняя остальные правила. Облачный агент не менял AGENTS.md и не установил watcher, hook или расписание. Пока LOCAL не подтвердил интеграцию, автоматическое обнаружение новых задач не доказано.

## Кто что меняет
CLOUD готовит исследование, тексты и задания; по текущему запросу владельца эта корневая документационная точка передачи — узкое дополнение к ранее разрешённому day research root. CLOUD не пишет main, код сайта, Worker/Access/D1/DNS и не делает внешние отправки.

LOCAL — единственный интегратор и деплойер. Он сначала сохраняет уже выполненное, выбирает независимую доступную задачу, затем связывает результат с её ID. Маркетинговый интерес не превращает исследовательскую запись в подписчика/активное агентство. Текущие продуктовые и медиа-gates сохраняются.

В папке запрещены реальные контактные выгрузки, персональные письма/документы, credentials, JWT/cookies, SQL dumps и скрытые платёжные маршруты. Даже если репозиторий открыт, документы должны быть безопасны для публикации. LOCAL исключает служебную папку из публичной сборки сайта.

## Получение и результат
Переходы: ready_for_local_review → accepted → in_progress → done / blocked / superseded. Не перезаписывать свежую чужую in_progress. Receipt LOCAL помещает в свою reviewed-ветку по пути `CLOUD-INBOX/receipts/<task-id>.json` и даёт ссылку/краткий результат в [issue #14](https://github.com/apodelenko-ctrl/WEGC/issues/14).

Обязательны source_commit_read, local_commit, проверенные/непройденные/непроведённые тесты, фактически изменённый объём и remaining holds. Сообщение CLOUD в issue — передача, не подтверждение получения на Mac. Сейчас receipt отсутствует.
