# EXPO25 — проверка опубликованных маршрутов без новых заявок

`python -m unittest -v test_route_check.py` — тесты монитора на синтетических ответах.

`python route_check.py --out LIVE-GET-CHECK.json` — девять фиксированных GET-запросов к действующим страницам МИРА; нужны Python 3 и curl. Внешние формы, письма, логин, cookies и D1-записи отсутствуют. Конфигурация curl пользователя отключена. Redirect на Access не открывается; в отчёте нет его query-параметров, заголовков, токенов или тела страницы. Временные ответы удаляются.

PASS означает только доступность страниц, наличие формы/согласия/Turnstile и анонимную границу доступа. Это не новая отправка заявки, не проверка прохождения Turnstile, не доставка письма, не обычный участник под логином и не тест России без VPN. При недоступности транспорта результат UNVERIFIED, а не «сайт упал».
