# VIVI — live supply gate,26 сентября 2026

Цель: превратить реальный запрос агентства в точный запрос The Title и не выдавать каталог за остатки. Пакет не отправляет писем, не открывает форму, не пишет в D1 и не хранит покупателя/контакты/договоры/цены.

`vivi-gate.json` — публичный санитарный checkpoint. Он фиксирует доказанную историю отношений WET/Rhom Bho, сообщение24.09 в существующем приватном треде и текущий официальный discovery-сигнал. Все меняющиеся коммерческие поля остаются `null`, project enablement — `false`.

`vivi_gate.py` — fail-closed проверка приватного case JSON. Живой ответ по наличию считается готовым только если связан с конкретным запросом агентства и конкретным запросом застройщику, получен после него напрямую от застройщика, имеет `inventory_as_of` и явный результат: список полностью процитированных юнитов либо `none_available`. Старый прайс, официальный маркетинговый статус, агрегатор или ответ по другой заявке не проходят.

Коммерческое включение дополнительно требует семь актуально проверенных приватных контролей: покрытие договора, продавец, комиссия, регистрация, защита лида, право работы через партнёрское агентство и media scope. Регистрация клиента требует отдельного developer acknowledgement. Private references/conditions остаются вне Git; публично сохраняется только результат проверки.

Проверка: `python -m unittest -v test_vivi_gate.py`, затем `python vivi_gate.py vivi-gate.json --out VIVI-GATE-RESULT.json`. Для публичного шаблона ожидается безопасный HOLD без ошибок: response/commercial/registration false, все семь mutable controls missing.
