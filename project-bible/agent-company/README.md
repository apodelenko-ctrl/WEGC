# Agent Company Infrastructure — библиотека проекта

Рабочее обозначение: **ACI / Agent Company Infrastructure**. Техническое имя, не утверждённый бренд.

Дата основания: 2026-09-19. Владелец продукта: Артём. Координатор: ASTRA.

## Где находится проект

- Репозиторий: `apodelenko-ctrl/WEGC` (публичный).
- Ветка: `agent-company/bootstrap-20260919`.
- База: `4972b4bca407d6944ca39dfacc810dc16147efbb` из main.
- Единственная область записи: `project-bible/agent-company/`.

Ветка наследует историю WEGC и не является отдельным репозиторием или границей приватности. Новые материалы отделены каталогом; main, МИРА и deployment не изменять. Здесь не хранятся KYC, персональные документы, банковские реквизиты, ключи или закрытые коммерческие условия.

## Суть

API-first сервис, предоставляющий ИИ-агенту компанию и инструменты бизнеса. Реальный собственник и уполномоченные лица сохраняются; агент работает в рамках отзываемого мандата. Основная гипотеза — оператор предоставляет действительное владение и корпоративное управление, а не только оформляет компанию на внешнего клиента.

## Работа и проверки

Из корня репозитория:

```bash
python project-bible/agent-company/scripts/validate_project.py
python -m unittest discover -s project-bible/agent-company/prototype -p 'test_*.py' -v
```

Перед работой читать AGENTS, Решения и статусы. Для каждого результата сохранять receipt. Публикация провайдера не равна нашему тесту; submitted не равно approved; подготовленный агент не равен запущенному worker.

## Разрешения

Разрешены документация, исследования, локальные тесты и подготовка интеграций. Письма, формы, регистрации, покупки, финансовые подключения и production deployment — после отдельного owner approval. Постоянный runtime специализированных агентов пока не запущен.
