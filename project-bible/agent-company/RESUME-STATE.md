# RESUME-STATE

Дата: 2026-09-19. Проект: Agent Company Infrastructure, рабочий код ACI.

## Контекст, который нельзя потерять

Владелец хочет сервис именно для агентского бизнеса: API-запрос → реальная компания с настоящим собственником со стороны сервиса → операционные права агента. Не заменять это обычной регистрацией на внешнего клиента; client-owned — другой режим.

Wyoming и doola — предложения для проверки, не окончательно утверждённые решения. Собственник и responsible party — не обязательно одна и та же роль. Банковское обслуживание не следует автоматически из регистрации.

## Честность статусов

Фоновый runtime не запущен. Prompts/roles/queue не равны работающим процессам. Любой будущий dispatch должен иметь внешнюю среду, run ID и подтверждение получения. После завершения интерактивной сессии её вычисления не продолжаются сами.

## Запрет на ложные результаты

Не писать `formed`, `EIN issued`, `bank approved`, `paid` без соответствующего внешнего доказательства. В mock-сценариях использовать явную маркировку simulation. Не ставить `done` задаче юридического согласования по собственному исследовательскому memo.
