## Важные ограничения прототипа

Actor — синтетическая роль теста, а не аутентификация. Нет сети, настоящего API server, persistence, проверки настоящих webhooks, EIN и банковской интеграции. Все результаты simulation. Модель не является production security boundary.

## Что ждёт внешнего этапа

Разрешение на конкретную отправку партнёрских запросов; проверка правовой модели; реальные ответы провайдеров и ключи; приватное хранилище; утверждённый бюджет/deployment; разрешение на регистрацию и пилот. Не подменять эти результаты документацией.

## Правило статусов

Наличие промпта не равно запущенному worker. LOCAL dispatch требует подтверждения, постоянный runtime — среды и фактических run IDs. `formed`, `EIN issued`, `bank approved`, `paid` разрешены только с соответствующими внешними доказательствами; `sim:` никогда не считается таким доказательством.
