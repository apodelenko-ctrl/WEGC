# 02 — Рынок и конкуренты

Дата первоначального исследования: 2026-09-16.

## Вывод в одном абзаце

Категория уже существует: на рынке есть международные платформы, партнёрские сети и брокерские агрегаторы, связывающие застройщиков и агентов. Это подтверждает жизнеспособность модели. При этом в русскоязычном сегменте большинство предложений построены вокруг реферальной логики «передайте клиента — получите часть комиссии». Наша ниша: **агентство сохраняет клиента, работает под своим брендом, получает до 90% комиссии и получает в том же контуре решение по оплате зарубежной недвижимости для клиентов из России / Беларуси / СНГ**.

## Основные игроки

### 1. Kalinka Thailand

Источник: https://kalinka-thailand.ru/partnership

Публичный оффер:

- до 70% комиссии;
- 200+ партнёров;
- брендированные подборки;
- фиксация клиента;
- юридическое сопровождение;
- отслеживание сделки;
- выплаты: банк, криптовалюта, наличные;
- отдельная реферальная ссылка для блогеров и партнёров.

Что копировать как механику:

- крупная цифра комиссии в первом экране;
- социальное доказательство;
- быстрый вход;
- показ «сделки / выплаты / новые партнёры»;
- Telegram / WhatsApp / VK / MAX как каналы отправки материалов.

Что делать иначе:

- не забирать клиента;
- не продавать только Пхукет;
- не ограничивать агента ролью партнёра Kalinka;
- сделать агентство самостоятельным владельцем клиентских отношений.

Сильная сторона: понятная человеческая модель входа и персональный куратор.

Слабое место относительно нашей гипотезы: агент передаёт клиента операционной команде платформы.

- отдельный партнёрский продукт для агентств.

## Карта конкурентных моделей

### Тип A — классическая реферальная сеть

Пример: Kalinka / OnlyBrokers / многие локальные агентства.

Модель: передайте клиента → мы ведём → делим комиссию.

### Тип B — международное агентство с партнёрами

Пример: Intermark.

Модель: широкий портфель + экспертиза + партнёрские отношения + возможность делегировать клиента.

### Тип C — технологический агрегатор / SaaS

Пример: Alnair.

Модель: данные, каталог, white label, PDF, API, подписка.

### Тип D — международная распределительная сеть

Пример: Signature Oasis.

Модель: брокеры ↔ платформа ↔ застройщики, единый кабинет, защита лидов, аналитика, централизованный инвентарь.

### Тип E — платёжный агент

Пример: Доверка.

Модель: рубли / локальная валюта на входе → международный платёж по документам → получатель за рубежом.

## Наша комбинация

Мы хотим объединить лучшие элементы C + D + E:

- маркетплейс и white-label инструменты;
- сеть агентств и застройщиков;
- договорный и комиссионный контур;
- платёжное сопровождение;
- агрессивную экономику для агента;
- сохранение клиента у агентства.

## Главный незакрытый вопрос рынка

Нужно отдельно проверить, есть ли игрок, который одновременно делает на русскоязычном рынке все четыре функции:

1. каталог глобальных застройщиков;
2. работа агентства под своим брендом;
3. 80–90% комиссии агентству;
4. встроенная возможность оплаты зарубежной недвижимости клиентом из РФ / Беларуси / СНГ.

На первом проходе полного совпадения не найдено.
