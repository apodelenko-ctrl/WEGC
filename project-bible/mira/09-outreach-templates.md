**Тема C:** Зарубежная недвижимость под вашим брендом — до 90% комиссии агентству

## Когда сеть уже имеет статистику — усиленная версия

Вместо общих слов вставлять только реальные цифры:

- number of connected agencies;
- active brokers;
- number of agencies that selected this market;
- registered buyer demand;
- completed transactions;
- target buyer geography.

Никогда не писать выдуманные «150 агентств», «полтора миллиона ожидаемых сделок» и т.п. до появления фактических данных.

# 5. Что тестировать в первых 100 контактах

Для агентств A/B тестировать:

- «не отдавайте клиента»;
- «до 90% комиссии»;
- «Пхукет в ассортименте за один день»;
- «оплата из России / СНГ»;
- «без иностранной компании».

Не смешивать все преимущества в одной теме письма. Тема должна проверять одну боль.

Для застройщиков тестировать:

- «network of agencies»;
- «Russian-speaking buyer distribution»;
- «single relationship / multiple agencies»;
- «verified demand for your market» — только когда данные реально собраны.

# 6. Минимальная дисциплина outreach

- отдельный адрес / домен для outbound после выбора бренда;
- SPF / DKIM / DMARC;
- небольшие партии;
- персонализация первой строки;
- дедупликация;
- журнал ответов;
- opt-out;
- не слать вложения в первом холодном письме;
- одна основная ссылка;
- фиксировать причину отказа;
- использовать ответы для изменения оффера.
