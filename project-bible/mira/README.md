> **МИРА — Международная инфраструктура риэлторских агентств.** Название принято владельцем проекта как публичный бренд. Отдельный IP / trademark / domain clearance не является активным naming-потоком и не блокирует текущую продуктовую работу.

## 1. Что строим

МИРА — B2B-платформа для российских, белорусских и русскоязычных агентств недвижимости, которая позволяет небольшому или среднему агентству добавить зарубежную недвижимость в собственный ассортимент без необходимости самостоятельно строить международную инфраструктуру.

Ключевой смысл для агентства:

**Ваш клиент. Ваш бренд. Зарубежная недвижимость разных стран. Наша международная инфраструктура.**

Агентство сохраняет клиента и ведёт отношения под своим брендом. Платформа даёт доступ к зарубежным застройщикам, объектам, регистрации лида, договорной инфраструктуре, расчёту агентской комиссии и отдельному платёжному сопровождению покупателя.

Для застройщика МИРА — это не ещё одно локальное агентство, а **единый канал доступа к распределённой сети агентств и их клиентам**.

## 2. Главные решения на текущий момент

1. Не позиционировать продукт как «партнёрскую программу» или «передайте нам клиента».
2. Главная категория: **готовое международное направление внутри агентства** / маркетплейс зарубежной недвижимости для агентств / международная сеть продаж недвижимости.
3. Главный оффер агентству: **«Превратите своё агентство в международное»**.
4. Главная формула продаж: **«Вы отвечаете за клиента. МИРА отвечает за международную инфраструктуру сделки.»**
5. Агентство не обязано передавать клиента внешнему брокеру. Клиент остаётся клиентом агентства.
6. Базовая коммерческая гипотеза запуска: **до 90% агентской комиссии застройщика — агентству; до 10% — платформе**. Это гипотеза для проверки юнит-экономики, а не окончательная тарифная политика.
7. Платёжное сопровождение покупателя — отдельная услуга и отдельная экономика. Не вычитать его автоматически из 10% платформы.
8. Для клиента из России / Беларуси / СНГ публично объясняем результат и доступность документированного платёжного сопровождения. Внутренние маршруты, компании, биржи и промежуточные юрисдикции публично не раскрываем.
9. Международная инфраструктура не ограничена РФ и СНГ: в будущем платформа должна поддерживать получение и выплаты в разных юрисдикциях и валютах через доступные корпоративные и банковские контуры.
10. На старте не строим тяжёлую CRM. Нужен **кабинет агентства / каталог / регистрация лида / статусы / комиссия / документы / запрос платёжного сопровождения**.
11. Первый рынок предложения — **Пхукет**. Следующие рынки подключаются после подтверждения спроса агентств и готовности supply-side.
12. Базовый onboarding: **подпишите партнёрский договор → получите доступ → зарегистрируйте первого клиента**.
13. Стандартная sales-воронка: `qualified agency → contact verified → conversation → demo → contract → onboarding → activated market → registered client → active deal`.
14. Phuket Field Ops — часть продукта: собственные фото, видео, field reports, локальная проверка проектов и поддержка агентств на месте.
15. Naming-поток закрыт. Старые naming-файлы сохраняются только как исторические материалы; новые naming-исследования не запускать без отдельного решения владельца проекта.
16. Старый лендинг `global-agent-desk/` считать ранним черновиком. Новый публичный прототип развивается отдельно в `/mira/`.

## 3. Двухсторонняя модель

### Сторона A — агентства

Агентство выбирает страны и направления, получает доступ к проектам и материалам, регистрирует клиента, проводит продажу под своим брендом и получает договорную долю комиссии.

### Сторона B — застройщики

Застройщик подключается один раз и получает доступ не к одному брокеру, а к сети агентств. По мере роста сети это превращается в сильный переговорный актив: лучшие комиссии, специальные условия, ранний доступ, выделенный инвентарь, специальные планы оплаты и маркетинговые бюджеты.

### Сетевой эффект

Больше агентств → больше покупателей → выше ценность для застройщиков → больше проектов и лучшие условия → выше ценность для агентств → больше сделок.
