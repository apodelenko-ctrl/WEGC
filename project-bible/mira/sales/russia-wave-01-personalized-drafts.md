Перед каждым сообщением обязательно:

1. повторно проверить текущую должность и канал;
2. убрать неподтверждённые утверждения о зарубежной активности адресата;
3. не обещать фиксированную комиссию без project terms;
4. не писать про внутренний payment route;
5. не отправлять без owner approval;
6. фиксировать `sent / replied / meeting / rejected` только после фактического действия.
