# МИРА — canonical brand status

Дата решения: 2026-09-16

**Статус: МИРА — финальный публичный бренд продукта.**

Расшифровка: **Международная инфраструктура риэлторских агентств**.

Это решение владельца проекта зафиксировано в `08-decisions-log.md`. Старые документы, где МИРА называется `рабочим названием`, `codename` или где продолжается поиск Estara / Domera / Terrava / Brivana / Novera и других вариантов, считать историческими research artifacts, а не действующей инструкцией.

## Что использовать во всех новых материалах

- Бренд: **МИРА**.
- Основной оффер: **Превратите своё агентство в международное.**
- Ключевая формула: **Ваш клиент. Ваш бренд. Ваша комиссия. Наша международная инфраструктура.**
- Категория для агентств: **B2B-маркетплейс зарубежной недвижимости для агентств** / **готовое зарубежное направление внутри агентства**.
- Для developer-facing материалов допустимо: **международная сеть продаж / дистрибуции недвижимости**.

## Что больше не делать

- не генерировать новые названия вместо МИРА;
- не называть МИРА временным codename;
- не оставлять naming research в активном backlog;
- не менять бренд автоматически по результатам старого shortlist.

## Что остаётся открытым

Отдельная задача — IP / trademark / domain clearance. До её завершения нельзя утверждать, что:

- товарный знак МИРА зарегистрирован;
- название юридически эксклюзивно;
- конкретный домен свободен или принадлежит проекту.

IP clearance не отменяет принятое продуктовое решение использовать МИРА как бренд в текущих материалах и прототипе.
