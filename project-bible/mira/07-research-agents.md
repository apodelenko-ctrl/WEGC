# 07 — План исследовательских агентов

## Задача

Разбить исследование на параллельные рабочие потоки так, чтобы результаты можно было объединить в одну структурированную базу, а не получить 20 несопоставимых текстовых отчётов.

## Правило для всех агентов

Каждый агент должен возвращать **строго структурированные строки данных + источники + дату проверки**. Нельзя вносить неподтверждённые цены, комиссии, email, телефоны или факты.

Если данные не подтверждены — поле `unknown` / `не найдено`, а не догадка.

---

# Поток A — агентства РФ

## Цель

Собрать живые агентства, которые потенциально могут продавать зарубежную недвижимость своим текущим клиентам.

## Приоритетные сегменты

### A1 — новостройки / инвестиционная недвижимость

Высший приоритет.

Признаки:

- продают новостройки;
- работают с инвесторами;
- бюджеты выше среднего;
- есть отдел продаж;
- ведут соцсети;
- есть руководитель / собственник в открытом доступе.

### A2 — региональные агентства с сильным локальным брендом

Целевая гипотеза проекта.

Пример профиля: 5–50 сотрудников, устойчивое присутствие в регионе, хорошие отзывы, свой сайт, активный поток клиентов, зарубежка отсутствует или представлена слабо.

### A3 — независимые брокеры

Только если есть признаки реального потока клиентов и профессиональной деятельности.

### A4 — уже продают зарубежку

Не исключать. Им можно дать больше стран, более высокую комиссию, платёжное сопровождение или white-label каталог.

## Поля базы

- `company_name`
- `city`
- `region`
- `website`
- `email`
- `phone`
- `telegram`
- `whatsapp`
- `vk`
- `instagram`
- `youtube`
- `director_or_owner`
- `director_contact`
- `team_size_estimate`
- `segments`
- `new_builds_yes_no`
- `foreign_property_yes_no`
- `foreign_markets`
- `premium_signal`
- `activity_signal`
- `lead_score_0_100`
- `why_relevant`
- `source_urls`
- `last_verified`

## Исключать

- закрытые / мёртвые сайты;
- каталоги без признаков реального агентства;
- агрегаторы объявлений как агентства;
- компании без доступного контакта после разумного поиска;
- дубли филиалов, если решение принимается централизованно.

Отдельная команда на каждый рынок:

- Бали / Индонезия;

10. контакты partnership / international sales.

- выплаты;

- Telegram;

- вебинары;
- лид-магниты;

Важный объект наблюдения: **Доверка** по платёжной части и **Intermark** по медиа / исследованиям.

# Поток H — источники баз

Нужно найти не агентства по одному, а **источники массового discovery**:

- профессиональные ассоциации;
- каталоги агентств;
- франчайзинговые сети;
- карты / бизнес-каталоги;
- выставки;
- конференции;
- рейтинги агентств;
- каталоги новостроек с партнёрами;
- публичные CRM marketplaces;
- базы юридических лиц только как источник названий, не как подтверждение активности.

Каждый источник оценить:

- покрытие;
- актуальность;
- можно ли извлечь контакты законно и технически;
- качество;
- дубли;
- стоимость;
- ограничения использования.

---

# Поток I — правовые карточки стран

Не использовать блог как единственный источник правового вывода.

Приоритет источников:

1. закон / регулятор;
2. налоговая / министерство;
3. официальное руководство;
4. лицензированный профессиональный орган;
5. крупная юридическая фирма — только как вторичный комментарий.

Результат — не юридическое заключение, а checklist вопросов, которые нужно закрыть перед запуском страны.

# Поток J — нейминг

Отдельное исследование:

- 50–100 русскоязычных названий;
- короткие;
- легко произносятся;
- нет негативного сокращения;
- не звучат как финансовая пирамида / криптосервис;
- подходят для расширения за пределы недвижимости при необходимости, но всё же объясняют категорию;
- проверка поисковой выдачи;
- проверка доменов;
- первичная проверка конфликтующих брендов / товарных знаков.

Рабочее `МИРА` использовать только как codename до этой проверки.

# Как организовать 20 исследовательских агентов

Не запускать 20 одинаковых агентов на одну задачу. Предпочтительное разделение:

- 5 агентов — РФ по федеральным округам / крупным регионам;
- 2 — Беларусь / СНГ;
- 2 — источники массовых баз;
- 2 — Пхукет и существующие WEGC-данные;
- 2 — Бали;
- 2 — Вьетнам;
- 2 — Дубай;
- 2 — конкурентный маркетинг;
- 1 — контроль качества / дедупликация.

Итого: 20.

## Контроль качества

Нужен отдельный проход, который:

- дедуплицирует;
- проверяет домены;
- нормализует телефоны;
- валидирует email;
- удаляет мёртвые компании;
- объединяет филиалы;
- присваивает lead score;
- сохраняет ссылки на источники.

## Результат первой волны

Не «десятки тысяч строк», а **2–5 тысяч качественно квалифицированных агентств**, из которых первые 500 получают приоритет для ручного запуска.

## Outreach

Массовая рассылка не должна начинаться до:

- проверки списка;
- сегментации;
- подготовки домена / email-инфраструктуры;
- текста по сегментам;
- процедуры opt-out / соблюдения применимых правил;
- теста на небольшой группе.

Лучше 100 персональных писем с 20 ответами, чем 10 000 одинаковых писем с испорченной репутацией домена.
