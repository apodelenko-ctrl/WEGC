# 03 — Продвижение и выход на рынок

## Цель первого этапа

Не строить массовый потребительский бренд. Сначала создать **B2B-сеть агентств**, получить первые реальные запросы на направления и использовать эти запросы как рычаг в переговорах с застройщиками.

Целевой первый контур:

- 100–150 квалифицированных агентств;
- Пхукет как полностью покрытый стартовый рынок;
- первые реальные сделки;
- подтверждённая экономика 90/10 или её корректировка;
- данные о том, какие страны агентства хотят подключить следующими.

## Каналы привлечения агентств

### 1. Прямая работа с базой агентств

Основной канал старта.

Нужно собрать и квалифицировать:

- агентства недвижимости РФ;
- агентства Беларуси;
- русскоязычные агентства Казахстана / Армении / Грузии / других стран;
- независимых брокеров с собственной клиентской базой.

Данные:

- название;
- город;
- сайт;
- email;
- телефон;
- Telegram / WhatsApp;
- руководитель / собственник;
- размер команды;
- специализация;
- продаёт ли новостройки;
- есть ли зарубежная недвижимость;
- какие страны уже продаёт;
- признаки премиальной базы клиентов;
- активность сайта / соцсетей;
- источник;
- дата проверки.

### 2. Telegram

Нужен отдельный канал продукта.

Контент:

- новые страны и проекты;
- «что сегодня можно предложить клиенту»;
- специальные условия застройщиков;
- кейсы комиссий;
- инструкции по оплате зарубежной недвижимости;
- короткие обзоры рынков;
- вебинары;
- ответы на вопросы агентств;
- готовые подборки, которые агент может переслать клиенту.

Урок Intermark: медиа работает постоянно, а не только рекламными объявлениями.

### 3. Вебинары и живые презентации

Темы:

- «Как региональному агентству начать продавать Пхукет»;
- «Как не отдавать клиента московскому агентству»;
- «Как получить комиссию за зарубежную сделку»;
- «Как клиенту из России оплатить объект за рубежом»;
- «Пхукет за 45 минут: районы, застройщики, комиссии».

После Пхукета — отдельные запуски по каждой новой стране.

### 4. Партнёрские медиа и профессиональные сообщества

Нужно составить карту:

- Telegram-каналы для риелторов;
- ассоциации риелторов;
- франчайзинговые сети агентств;
- PropTech-сообщества;
- конференции недвижимости;
- обучающие школы брокеров;
- CRM / SaaS для агентств как потенциальные партнёры по аудитории.

### 5. Instagram / VK / YouTube / короткое видео

Не делать потребительский lifestyle-канал. Делать B2B-контент:

- короткие разборы комиссий;
- «объект недели для вашего клиента»;
- «как продать Пхукет, если вы агент в России»;
- интервью с застройщиком;
- обзор района;
- реальные вопросы агентств;
- пошаговый путь сделки.

### 6. PR через собственные данные

Intermark успешно создаёт исследования, которые затем цитируются СМИ. Нам нужно собирать собственный массив:

- спрос агентств по странам;
- средний бюджет зарегистрированных запросов;
- самые популярные рынки;
- динамика спроса;
- доля оплат из РФ / СНГ;
- сроки закрытия сделки;
- средняя комиссия;
- география агентств.

Из этого делать квартальные отчёты: **«Карта спроса российских агентств на зарубежную недвижимость»**.

Это одновременно PR, SEO, переговорный инструмент с застройщиками и доказательство масштаба сети.

## Воронка для агентства

1. Реклама / письмо / Telegram / рекомендация.
2. Лендинг: «Превратите своё агентство в международное».
3. Регистрация агентства.
4. Выбор интересующих стран.
5. Доступ к стартовому каталогу.
6. Короткое обучение / вводный звонок.
7. Агент регистрирует первый запрос или клиента.
8. Платформа помогает провести первую сделку.
9. После первой сделки — расширение на следующие рынки.

## Воронка для застройщика

1. Определяем спрос сети на конкретный рынок.
2. Собираем список застройщиков.
3. Выбираем приоритет по качеству продукта, комиссии, документам, репутации и наличию.
4. Письмо: «у нас X подключённых агентств, Y запросов по вашему рынку».
5. Переговоры по комиссии и условиям.
6. Агентский договор.
7. Загрузка проектов / материалов.
8. Активация сети агентств.
9. Отчёт застройщику по спросу и лидам.
10. Переговоры об улучшенных условиях по мере роста объёма.

## Что копировать у конкурентов без стеснения — как механику

- большая цифра комиссии на первом экране;
- защита клиента;
- кабинет и статусы;
- подборки и брендированные материалы;
- Telegram-канал;
- персональный куратор на старте;
- регулярные вебинары;
- специальные предложения застройщиков;
- социальное доказательство: агентства, сделки, комиссии, страны;
- простая форма регистрации;
- отдельные лендинги под каждую боль и страну.

Копировать механику, но не тексты, дизайн и чужие защищённые материалы.

## Ключевые рекламные сообщения для теста

### Вариант A

**Не отдавайте своего клиента. Продайте ему зарубежную недвижимость сами.**

### Вариант B

**Превратите своё агентство в международное за один день.**

### Вариант C

**До 90% комиссии застройщика — вашему агентству.**

### Вариант D

**Пхукет, Бали, Дубай — в ассортименте вашего агентства без зарубежного офиса.**

### Вариант E

**Клиент покупает зарубежную недвижимость. Вы остаетесь его агентом.**

### Вариант F

**Клиенту нужно оплатить объект из России? Сопроводим и эту часть сделки.**

## Метрики запуска

- стоимость квалифицированного агентства;
- регистрация → первый просмотр проекта;
- регистрация → первый запрос;
- запрос → зарегистрированный лид;
- лид → бронь;
- бронь → сделка;
- средняя комиссия платформы;
- срок выплаты агентству;
- доля сделок с платёжным сопровождением;
- количество активных агентств за 30 дней;
- число застройщиков / проектов на рынок;
- количество новых агентств по рекомендациям.
