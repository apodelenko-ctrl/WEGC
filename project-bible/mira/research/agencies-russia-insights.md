## Методика и качество

- Внесены только компании/бренды, для которых зафиксирована официальная веб-страница с услугами недвижимости или официальная страница регионального офиса.
- Для каждой строки указан URL источника и дата проверки; неизвестные e-mail, телефоны, Telegram и международный профиль оставлены пустыми или «не подтверждено».
- Федеральные сети с отдельными региональными доменами не считались автоматически доказательством отдельного юридического лица; перед outreach требуется сверка юридического лица и центрального партнёрского отдела.
- Рейтинг A/B/C — рабочая приоритизация для квалификации. Для новых региональных записей установлен B до проверки международного опыта и контакта партнёрского отдела.
- Массовый outreach не выполнялся.

## Приоритет квалификации

A: компании с явно заявленной зарубежной недвижимостью или крупной федеральной/премиальной сетью. B: действующие региональные агентства с каталогом и полноценным сайтом, международный профиль не подтверждён. C: не использовать до ручной проверки живости сайта, юридического лица и команды.

Первый outreach-подход следует строить через официальную форму/общий e-mail с просьбой соединить с руководителем партнёрского или международного направления. Прямые контакты не следует выводить из сторонних каталогов без отдельной проверки.

## Следующий проход

1. Дедуплицировать бренды федеральных сетей по юридическим лицам.
2. Для A/B найти на официальном сайте разделы «Партнёрам», «Сотрудничество», e-mail и Telegram/VK.
3. Добавить размер команды/масштаб только при наличии официального подтверждения.
4. Подготовить персонализированные черновики из 09-outreach-templates.md; отправка запрещена до отдельного решения.
