# Benchmark: «Диал» — региональное агентство с собственным зарубежным направлением

Дата проверки: 2026-09-16  
Рынок: Екатеринбург / Россия  
Тип: regional agency + partner-mediated foreign-property desk  
Статус: evidence-backed benchmark, не считать полноценным технологическим marketplace без дополнительных данных.

## Почему это важно для МИРА

«Диал» — полезный benchmark не потому, что это крупная международная платформа, а потому что компания уже реализует именно тот переход, который МИРА хочет продавать региональным агентствам: локальный российский бренд добавил зарубежную недвижимость в собственный продукт.

Это доказывает, что проблема и клиентский спрос существуют не только у московских международных агентств.

## Что это говорит о модели

По публичным материалам модель выглядит как:

`локальное агентство → собственный клиент → подбор внешнего зарубежного партнёра → совместная консультация / сопровождение`.

Это ближе к partner-mediated desk, чем к каталогу, где локальное агентство самостоятельно работает сразу с нормализованным developer supply через единый transaction layer.

## Что пока НЕ подтверждено

Не найдено первичное подтверждение следующих функций:

- единый developer marketplace;
- единый кабинет для внешних агентств;
- white-label SaaS для других агентств;
- централизованная регистрация клиента у зарубежных developers;
- единый commission ledger;
- единые developer agreements на широкую supply-сеть;
- стандартизированный lead protection;
- отдельный B2B payment-support layer для других агентств;
- публичная комиссия партнёру/субагенту.

Поэтому не называть «Диал» полным аналогом МИРА.

## Конкурентный вывод

«Диал» показывает, что региональное агентство может успешно продавать клиенту тезис «мы остаёмся вашим агентством и организуем зарубежную сделку через нашу партнёрскую сеть».

Для МИРА это означает:

1. Нельзя строить коммуникацию только вокруг тезиса «региональные агентства вообще не умеют продавать зарубежку» — часть уже умеет.
2. Для greenfield-агентств основной оффер остаётся: «откройте зарубежное направление внутри агентства».
3. Для агентств вроде «Диал» нужен другой оффер: **«не собирайте и не обслуживайте международную партнёрскую сеть вручную — подключите единый supply / registration / commission / transaction layer»**.
4. В CRM сегментации нужен отдельный класс `existing_foreign_property_desk`.
5. Такие агентства могут быть не только конкурентами, но и сильными ранними партнёрами: у них уже есть спрос, компетенция и сотрудник, отвечающий за направление.

## Рекомендуемый sales angle для existing desk

Не использовать:

> «Мы научим вас продавать зарубежную недвижимость».

Использовать:

> «У вас уже есть зарубежное направление. МИРА может дать ему единый доступ к developer supply, регистрации клиентов, коммерческим условиям, transaction support и следующим рынкам — без ручного построения отдельной партнёрской цепочки по каждой стране.»

## Следующая проверка

Если «Диал» попадёт в pilot outreach:

- выяснить, какие страны реально активны сейчас;
- понять, работают ли они через master brokers или напрямую с developers;
- проверить, кто получает/распределяет developer commission;
- понять client-registration и lead-protection process;
- узнать, есть ли интерес к Phuket developer layer;
- не предлагать им базовый «запустите зарубежку» pitch.
