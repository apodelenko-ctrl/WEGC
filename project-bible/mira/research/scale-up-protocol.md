# МИРА — протокол масштабирования после пилота

1. Сначала принять пилот после проверки количества уникальных организаций, доли строк с официальным сайтом, доли строк с прямым контактом и доли строк, где подтверждена зарубежная специализация.
2. Разделить воронку: агентства, уже продающие зарубежную недвижимость; агентства с первичкой/инвестиционной аудиторией без зарубежки; локальные сильные бренды.
3. Для каждого сегмента использовать отдельную тему письма и CTA из 09-outreach-templates.md.
4. Не отправлять очередь автоматически: сначала ручная проверка, SPF/DKIM/DMARC, opt-out и малая тестовая партия.
5. После первых ответов фиксировать причину отказа, интересующие страны, готовность к обучению и запрос на платёжное сопровождение.
6. Масштабировать только источники, которые дают действующие организации, а не каталожный шум.
7. Для застройщиков использовать накопленный спрос агентств как доказательство интереса рынка; цифры публиковать только после фактической фиксации.
